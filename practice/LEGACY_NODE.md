# Ритм · afanasev1

Мобильный сайт с дневником тренировок, цикличным ассистентом и интерактивной картой нагрузки.

## Попробовать

Открой сайт: он сразу покажет твой личный дневник. Выбери тему в ассистенте или добавь тренировку. Ответы сохраняются в локальной базе. Кнопка «Хочу добавить ещё» возвращает к выбору темы без ограничения количества записей. Распознанные упражнения нужно проверить и сохранить — только после этого они изменят карту тела.

Демо-данные не записываются в личный дневник. Профиль предзаполнен описанными предпочтениями и циклом, его можно изменить во вкладке «Обо мне».

## Что работает

- Личный профиль: цель, опыт, предпочтения, частота и последовательный цикл из четырёх отдельных тренировок.
- Четыре шаблона по программе пользователя: «Сила + руки», «Спина», «Ноги и остальное», «Грудь, трицепс и плечи». Выбор плана подставляет упражнения с пустыми подходами. Заполненные поля защищены подтверждением при смене плана.
- В начале каждого плана: подтягивания с целью 100 повторений суммарно, общая разминка, штанга, вакуум и пресс. Цель не подменяет результат. Пустые пункты шаблона не сохраняются; для разминки и вакуума есть отметка выполнения и свободная заметка.
- Локальная база SQLite: записи, сообщения, профиль и настройки сохраняются между сессиями в `data/diary.sqlite`.
- Дневник тренировок, массы тела, сна, питания, самочувствия и любых заметок.
- Вкладки дневника по типам записей: тренировки, вес, сон, питание, самочувствие, заметки и отдых. Кнопка добавления открывает выбранный тип; отдельное название записи не требуется.
- Отдельные подходы: сначала вес, затем повторения, тяжесть по ощущениям и отметка разминки; добавление и копирование предыдущего подхода. Можно полностью очистить число и ввести дробный вес через точку или запятую.
- Отдельные области бицепса и предплечий на карте тела; старые записи с общей группой «Руки» не распределяются между ними автоматически.
- Несколько групп мышц у упражнения, пустой выбор и отдельная категория «Сила». Подсказки названий из истории помогают продолжать один график. Регистр, лишние пробелы и известные синонимы объединяются; разные варианты упражнений сохраняются отдельно.
- Интерактивная схема тела спереди/сзади: условный процент нагрузки со спадом за 14 дней. Периоды 7/30/90 дней меняют историю в деталях, а не текущий индекс.
- График массы тела и изменения от первого замера с периодами 30/90 дней и всей историей. Под ним — сопоставление изменения массы тела с рабочими весами упражнений категории «Сила».
- График каждого упражнения: дата по X, дополнительный вес по Y, повторения внутри отдельной метки каждого подхода. Одинаковые подходы не пропадают; доступны подробности по нажатию и таблица.
- Обзор тренировок и наблюдения о длительных перерывах.
- Цикл предлагает следующий план после последней сохранённой тренировки с номером плана: 1 → 2 → 3 → 4 → 1, независимо от недель и дней отдыха. Это одна тренировка за занятие. Редактирование существующей записи не подставляет план заново.
- Режим структурированных вопросов работает локально и сохраняет ответы.
- Вкладка «Советы» показывает наблюдения, рассчитанные по записям дневника на этом компьютере.
- Тёмное графитово-платиновое оформление с прежней компоновкой.
- Напоминания в приложении, системные уведомления при открытой странице и файл для ежедневного напоминания в календаре.
- Экспорт личного дневника в JSON, редактирование, мягкое удаление и отмена удаления.
- Установка сайта на главный экран через PWA. Для чтения и записи нужен запущенный локальный сервер Node.js; интернет после установки зависимостей не нужен.

## Локальный запуск и перенос на другой Mac

Ритм работает на этом компьютере через Node.js. Дневник хранится в обычном файле `data/diary.sqlite` внутри папки проекта. Интернет, Cloudflare и ключ ИИ для чтения и записи тренировок не нужны.

На Mac, где уже есть Node.js 22.13 или новее и зависимости проекта, открой папку `afanasev1` и дважды нажми `start.command`. То же самое из терминала: `./start.command`. Оставляй окно терминала открытым и перейди по адресу, который оно покажет (обычно http://localhost:5173).

Если появится сообщение о недостающих зависимостях, один раз установи их на этом Mac командой `npm ci` из папки проекта. Для установки пакетов понадобится интернет; после установки сам дневник работает без сети. Проверить базу можно командой `npm run setup:local`. Кнопка входа для локальной версии не нужна.

### Перенос через флешку

1. Закрой Ритм на первом Mac сочетанием Ctrl+C в терминале.
2. Скопируй **всю папку `afanasev1`**, включая видимую папку `data`, на флешку.
3. На втором Mac открой перенесённую папку. Убедись, что внутри есть `data/diary.sqlite`.
4. Если Node.js не установлен, установи совместимую с этим Mac версию Node.js 22.13+. Если не хватает зависимостей, выполни `npm ci`.
5. Запусти `./start.command` или двойным щелчком открой файл. Новые записи будут сохраняться в **этом же** `data/diary.sqlite` на втором Mac.

В текущую базу перенесены 8 тренировок и 6 записей веса. При следующем переносе копируй папку с того Mac, на котором делал последние записи: автоматической синхронизации между компьютерами нет. Не заменяй более новую базу старой копией. Файл базы содержит личные данные; храни флешку соответственно.

Раздел «Советы» и диалог вопросов работают по данным дневника локально. Отправки записей в OpenAI нет.

### Очистка дневника

Останови локальный сервер через Ctrl+C, затем выполни `npm run db:reset`. Подтверди действие словом «СБРОСИТЬ». Команда сначала сохранит копию базы в `data/backups/`, затем очистит тренировки, вес, сообщения, профиль и старые советы. Проверка после сброса: `npm run db:status`. Для Docker используй команды из [DOCKER.md](DOCKER.md).

## Как читать карту

Это **условный индекс записанной нагрузки**, а не оценка тонуса, физиологического восстановления или готовности к тренировке.

- Коэффициент усилия: легко 0,18; рабочий 0,5; тяжело 0,85; почти предел 1.
- Поправка повторений: `clamp(sqrt(reps / 8), 0.65, 1.25)`.
- Спад: `max(0, 1 − ageDays / 14)`. Будущие записи исключены; на 14-й день вклад равен нулю.
- Вклад подхода — произведение этих трёх величин, разделённое поровну между выбранными анатомическими группами. Категория «Сила» получает полный вклад независимо и не забирает долю мышц. Индекс группы: `round(100 × (1 − exp(−sum / 6)))`.

Коэффициенты — выбранные настройки продукта, не научно валидированная шкала. 14 дней — окно учёта, а не утверждение о сроке полного восстановления мышц. Килограммы разных упражнений не сравниваются; вес хранится для отслеживания прогрессии. Поэтому лёгкие подходы на руки не равны по вкладу тяжёлым подходам на ноги. Масштаб нагрузки оценивает сам пользователь относительно своих возможностей.

Разминка, косвенная нагрузка, упражнения без группы и подходы без оценки тяжести в сумму не входят. Если недавние подходы есть, но их тяжесть неизвестна, показывается «—». Если часть известна, показывается «≥» — нижняя оценка. Группы без истории также обозначены «—». Отсутствие записей не равно отсутствию активности; группам не обязательно нужна одинаковая нагрузка.

## Как читать графики

Вкладка «Дневник → Тренировки» показывает все подходы выбранного упражнения. X — календарная дата, Y — дополнительный вес в килограммах; число в метке — повторения. Подходы одной даты немного разнесены по горизонтали, если иначе перекрываются. Разминка выделена пунктиром, 0 кг означает отсутствие дополнительного веса. Это история подходов, а не автоматическая оценка интенсивности или силы.

Вкладка «Дневник → Вес тела» показывает массу или изменение относительно первого замера выбранного периода. Несколько измерений одного дня усредняются. Для текстового вывода нужны хотя бы четыре разных дня измерений с интервалом от 14 дней, минимум по два в каждой половине периода. Сравниваются медианы этих половин; разница до 0,3 кг считается небольшой.

Для сопоставления с силовыми отметь нужные упражнения категорией «Сила». Сравнение использует одинаковые названия, повторения и тяжесть подхода, без разминки и без 0 кг. Если тяжесть неизвестна с обеих сторон, подходы сравниваются с этой неопределённостью. Между тренировками должно пройти от 7 дней, они должны попадать в разные половины периода измерений массы тела. Для каждой половины берётся медиана лучших рабочих весов за день. Изменение до 2% считается небольшим; разнонаправленные изменения разных упражнений показываются отдельно как смешанная тенденция. Пороги — настройки продукта. Подробнее о выбранных подходах и методе можно прочитать под графиком.

Подсказки используют историю пользователя и ограниченный словарь явных синонимов (например, «присед» и «приседания», «брусья с доп весом» и «отжимания на брусьях с дополнительным весом»). Старые записи объединяются при построении графика без перезаписи базы. Разные тренажёры, техника и варианты упражнения автоматически не объединяются.

## Напоминания

- По умолчанию: после 3 дней без записи. Порог, время и пауза меняются в настройках.
- Отметка отдыха на текущую дату убирает наблюдения на этот день.
- Системное уведомление может появиться после указанного времени только при открытом сайте и разрешении браузера, максимум раз в день на устройстве.
- Фоновые Web Push при закрытом сайте пока не реализованы. Для них нужен серверный планировщик и подписки устройств.
- Файл `.ics` добавляет независимое ежедневное напоминание в календарь после открытия пользователем. Календарь не синхронизируется с дневником; отменять/менять событие нужно в календаре.

## Проверки

```sh
npx tsc --noEmit
node scripts/check-domain.mjs
node scripts/check-plans.mjs
node scripts/check-progress.mjs
node scripts/check-local.mjs
# При запущенном локальном сервере:
node scripts/check-api.mjs
npm run build
```

Проверяются расчёты дневника, целостность локальной базы и работа интерфейса. После запуска проверь чтение существующих тренировок и сохранение новой записи.

## Структура

- `app/fitness-app.tsx` — обзор, дневник, профиль и напоминания.
- `app/assistant-panel.tsx` — разговор и цикл вопросов.
- `app/advice-panel.tsx` — локальные наблюдения по дневнику.
- `app/entry-editor.tsx`, `app/exercise-name-input.tsx` — форма записи, выбор групп и подсказки упражнений.
- `app/journal-panel.tsx` — разделы дневника.
- `app/body-map.tsx`, `app/weight-chart.tsx`, `app/exercise-progress.tsx` — интерактивные диаграммы.
- `lib/progress.ts` — история подходов и сопоставление тенденций.
- `app/api/diary/route.ts` — локальное API дневника.
- `lib/fitness.ts`, `lib/validation.ts` — расчёты и проверка данных.
- `db/` — работа с локальной SQLite-базой; `data/diary.sqlite` — личные записи.
- `public/` — персонаж, иконки и PWA.

React + TypeScript, Vinext/Vite, Node.js и SQLite. Локальная база исключена из Git, но входит в папку для переноса через флешку. Иллюстрация создана специально для Ритма; детали в `ASSETS.md`.
