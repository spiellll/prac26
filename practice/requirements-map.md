# Как дневник тренировок «Ритм» соответствует учебному заданию

Проект практики — существующий сайт дневника тренировок. Тренировка,
измерение веса, запись сна и свободная заметка являются видами записи
дневника. Поэтому предметную область сервиса заметок можно показать на
реальных функциях этого проекта: создать, прочитать, изменить и удалить
запись. Интерфейс React с картой тела и графиками сохраняется.

Этот файл описывает реализацию и способы её проверки. Он не подтверждает,
что студент уже изучил каждую тему или выполнил действия вручную.

## Выбор технологий

- **Flask** выбран для Python API; отдельный учебный сервер находится в
  `backend/`. Интерфейс дневника остаётся прежним.
- **SQLite** выбран для локального хранения в `data/diary.sqlite`.
  Переносимыми данными являются файлы базы и экспорт дневника, а не история
  диалога с ChatGPT. Перед переносом следует остановить приложение и
  использовать предусмотренное проектом резервное копирование.
- **JSON** — формат запросов, ответов и экспорта. JSON не заменяет СУБД:
  SQLite хранит данные, а API передаёт их в JSON. Не нужно реализовывать
  несколько конкурирующих хранилищ только из-за перечисления в задании.
- **SQLAlchemy** используется Python backend для работы с таблицами.
- **PostgreSQL** — возможный вариант для внешнего хостинга с постоянным
  хранилищем. Если преподаватель требует именно демонстрацию PostgreSQL
  через DBeaver, потребуется отдельно подключить PostgreSQL и проверить
  запросы; локальный SQLite эту конкретную тему не подтверждает.

## Проверка мини-проекта с логами

Из корня проекта:

```bash
python3 -m log_tools.process_logs log_tools/sample.log --strict
python3 -m unittest discover -s log_tools -v
```

В примере 10 запросов, один ответ 500, нет ошибочных строк. Вложенные
циклы и Counter должны выдавать одинаковые количества статусов.
Параметр `--strict` возвращает код 2, если в журнале есть нераспознанные
строки; номера строк остаются в JSON-отчёте.

`n` — число записей, `m` — число различных статусов. Для реального HTTP
набор статусов ограничен, поэтому это сравнение способов группировки,
а не утверждение, что любой HTTP-журнал имеет квадратичную сложность.

## Что считается готовым хостингом

Готовый Dockerfile, файл конфигурации Render и локальный адрес
`127.0.0.1` ещё не являются публичным демо. Для завершения нужно получить
HTTPS-адрес, открыть сайт извне, создать тестовую запись, обновить страницу
и убедиться, что запись сохранилась после перезапуска сервиса. Для SQLite
на хостинге нужен постоянный диск; при его отсутствии выбирается другое
постоянное хранилище, например PostgreSQL.
