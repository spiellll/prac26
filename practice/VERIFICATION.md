# Фактическая проверка версии Ритм для практики

Проверено 2 ноября 2026 года на macOS с Python 3.9.6 и Node.js 24.22.1.

- `.venv/bin/python -m pytest -c backend/pytest.ini backend/tests log_tools -q`:
  **66 passed**. Все изменяющие запросы тестов работают с временными базами.
- `pip check`: нет нарушенных зависимостей. `pip freeze` записан в
  `backend/requirements-lock.txt`.
- Проверки `check-domain.mjs`, `check-plans.mjs`, `check-progress.mjs` прошли.
- `tsc --noEmit` и `vite build --config vite.practice.config.ts` прошли.
- Flask открыл прежний интерфейс на `127.0.0.1:5001`. Во вкладке дневника
  отображаются все 14 действующих записей: 8 тренировок и 6 измерений веса.
- Содержимое четырёх таблиц личной базы после чтения через Flask и браузер
  совпадает с резервной копией, созданной перед адаптацией.
- Gunicorn запускался с временной SQLite в `PUBLIC_DEMO=1`. Проверены
  главная страница, REST создание/удаление, раздельные cookie двух клиентов
  и сохранение записи после перезапуска процесса с тем же секретом.
- Сброс SQLite проверен только на синтетической временной базе: все таблицы
  очищены, все прежние строки присутствуют в созданной резервной копии.
- Common Log Format обработан: 10 запросов, одинаковый результат вложенных
  циклов и Counter, нераспознанных строк нет.

Не подтверждены: сборка/запуск контейнера Docker на этом компьютере
(Docker CLI отсутствует), работа на PostgreSQL и внешняя публикация.
Конфигурации подготовлены; проверенная публичная ссылка добавляется
после подключения аккаунта хостинга и успешного развёртывания.
